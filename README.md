# ADR-T

ระบบบันทึกและติดตามอาการไม่พึงประสงค์จากยาเคมีบำบัด (Chemotherapy ADR Monitoring System)

## Features

- บันทึกข้อมูลผู้ป่วย
- บันทึกยาเคมีบำบัดที่ได้รับ
- ประเมินอาการตาม CTCAE Grade 1–5
- เพิ่มอาการอื่นเพิ่มเติมได้
- Dashboard สรุปข้อมูล ADR
- รายงานรายเดือน / รายปี
- Export รายงาน
- แก้ไข / ลบข้อมูล
- พิมพ์เอกสารส่งต่อผู้ป่วย

## Tech Stack

- React
- Vite
- Tailwind CSS
- LocalStorage

## Installation

```bash
npm install
